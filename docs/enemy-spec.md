# 敵キャラクター仕様書

敵キャラクターの能力・攻撃・防御・耐性・宝箱の仕様。プレイヤーと同じルール（`docs/character-spec.md`）を敵にも適用する。

この文書は仕様であり、実装の根拠として扱う。変更する場合は必ずユーザーの承認を得ること。

- **確定**: ユーザーが承認した仕様。
- **未決**: これから決める内容。

## 1. 基本方針【確定】

- 敵にも、プレイヤーと同じ条件（レベル、能力、攻撃・防御の数値、クリティカル、回避）を適用する。
- 攻撃は「ダイス（2d6+xx のような数値）」と重さ、防御も同様に、プレイヤーと同じ計算式（攻撃値 → ダメージ表、防御の合算、回避、クリティカル）を使う。
- 敵ごとに、耐性（武器・魔法）と、宝箱ランクを持つ。

## 2. 敵が持つ項目

| 項目 | 内容 | 状態 |
|---|---|---|
| `level` | 敵のレベル（攻撃値・回避などの加算に使う） | 確定 |
| 能力値 | 筋力、生命力、敏捷度など | あとで決める |
| 最大HP | 敵ごとに任意の値を直接指定（能力やレベルからは計算しない） | 確定 |
| MP | 基本は無限（消費しない） | 確定 |
| 攻撃 | 重さ、ダイス（n個のm面ダイス＋固定値）、攻撃属性 | 確定 |
| 防御 | 「2d6+xx」の1つの値（防具の部位には分けない） | 確定 |
| クリティカル | 基本率、リトライ回数 | 確定（値は敵ごとに決める） |
| 回避 | 敏捷度とレベルから計算 | 確定（敏捷度はあとで決める） |
| `weaponImmunity` | 武器の耐性（下記） | 確定 |
| `magicRates` | 属性魔法の有効率（下記） | 確定 |
| `chestRank` | 宝箱ランク | 確定 |
| 経験値、宝箱 | 敵のレア度や強さで決まる。敵の一覧を作るときに決める | 一覧作成時に決定 |
| 既存の項目 | `texture`、`aiType`、`speed`、`scale` など | 維持 |

### 攻撃属性

- 敵の攻撃には、属性がある: 無、炎、氷、雷、聖、闇、毒。魔法の属性（炎・氷・雷・聖・闇・毒）と同じ分類。
- 属性のある攻撃のダメージは、物理ダメージと属性ダメージに分かれる（例: 半々）。装備によって、ダメージが全く無くなってしまうことを避けるため。割合は敵ごとに決める。
- プレイヤー側の耐性は、装備に付く「防御属性」で表す。職業による耐性はない。
- 属性ダメージも、物理ダメージと同じ流れ（ダメージ表、防御の数値、レベルの加算、回避）で計算する。

```
属性ダメージ = ダメージ表[敵の攻撃の重さ][攻撃値] × 属性分の割合
防御         = 防具の合算（物理と同じ） ＋ 装備の防御属性の値（その属性のとき）
被ダメージ   = max(1, 属性ダメージ − 防御 − 回避)
```

- 防御属性は、強くしすぎて、ダメージが全く通らなくなることがないように、暫定の控えめな値にする（防御属性付き装備の一覧を決めるときに定める）。

## 3. 武器の耐性【確定】

敵ごとに `weaponImmunity` を1つ持つ。

| 値 | 通常の武器 | 魔法武器（+1以上） |
|---|---|---|
| `none`（既定） | 効く | 効く |
| `normal`（通常武器無効） | 効かない | 効く |
| `all`（武器全般無効） | 効かない | 効かない |

- 武器の+値は、魔法武器になることと、クリティカル率の上昇（+1ごとに+5%）だけ。+1と+2は、魔法武器としては同じ。
- 炎の剣のような武器も、属性の効果はなく、普通の+N武器（魔法武器）と同じ扱い。
- 無属性魔法は、普通の武器の攻撃と同じ扱い（`normal`、`all` の敵には効かない）。

## 4. 魔法の耐性【確定】

- 属性は、炎、氷、雷、聖、闇、毒の6種。
- 敵ごとに、属性ごとの有効率（%）を `magicRates` で持つ。未指定の属性は100%。
- 属性限定の敵は、「炎100%、他は0%」のように表す。
- 属性魔法は、敵の `weaponImmunity` に関係なく、属性ごとの有効率で決まる。

```json
"ghost":  { "weaponImmunity": "normal", "magicRates": { "fire": 150, "holy": 200, "dark": 0 } },
"wraith": { "weaponImmunity": "all",    "magicRates": { "holy": 200 } }
```

- 既存の魔法（ファイア、爆発、拡散、マジックボルトなど）への属性の割り当ては、魔法の仕様を決めるときに行う。

## 5. 宝箱ランク【確定】

- 全ての敵に、宝箱ランクを個別に、固定で決める。ランクは、木、銅、鉄、銀、金、漆黒の6段階（漆黒は、将来のレア敵・ボス用）。
- 強さに比例させない。雑魚でも、レアな敵なら、高いランクにする（はぐれメタル的な効果）。
- 現在の11種への割り当ては、`public/data/enemies.json` の `chestRank`。

| ランク | 敵 |
|---|---|
| 木 | スライム、ゴブリンアーチャー、マリア・モスキート |
| 銅 | ゴブリンシャーマン、パラサイト・ワスプ、巨大毒蛾、ポイズントード |
| 鉄 | スケルトン剣士、アシッド・ワーム |
| 銀 | タランチュラ・スワンプ |
| 金 | 人喰い箱ミミック |

## 6. 未決事項

- 物理ダメージと属性ダメージの割合の表し方、防御属性付きの装備の一覧と暫定の値。
- 既存の `maxHp`、`attackPower` の置き換え方と、既存11種の数値の再設計（敵キャラ一覧の作成時に行う）。
- 敵ごとの経験値、宝箱を落とす確率、箱の中身（敵キャラ一覧の作成時に行う）。
- 罠と鍵の難度。
