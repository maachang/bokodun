# 敵キャラクター仕様書

敵キャラクターの能力・攻撃・防御・耐性・宝箱の仕様。プレイヤーと同じルール（`docs/character-spec.md`）を敵にも適用する。

この文書は仕様であり、実装の根拠として扱う。変更する場合は必ずユーザーの承認を得ること。

- **確定**: ユーザーが承認した仕様。
- **未決**: これから決める内容。

## 1. 基本方針【確定】

- 敵にも、プレイヤーと同じ条件（レベル、能力、攻撃・防御の数値、クリティカル、回避）を適用する。
- 攻撃は「ダイス（2d6+xx のような数値）」と重さ、防御も同様に、プレイヤーと同じ計算式（攻撃値 → ダメージ表、防御の合算、回避、クリティカル）を使う。
- 敵ごとに、耐性（武器・魔法）と、宝箱ランクを持つ。

## 2. 敵が持つ項目

| 項目 | 内容 | 状態 |
|---|---|---|
| `level` | 敵のレベル（攻撃値・回避などの加算に使う） | 確定 |
| 能力値 | 筋力、生命力、敏捷度など | あとで決める |
| 最大HP | 敵ごとに任意の値を直接指定（能力やレベルからは計算しない） | 確定 |
| MP | 基本は無限（消費しない） | 確定 |
| 攻撃 | 重さ、ダイス（n個のm面ダイス＋固定値）、攻撃属性 | 確定 |
| 防御 | 「2d6+xx」の1つの値（防具の部位には分けない） | 確定 |
| クリティカル | 基本率、リトライ回数 | 確定（値は敵ごとに決める） |
| 回避 | 敏捷度とレベルから計算 | 確定（敏捷度はあとで決める） |
| `weaponImmunity` | 武器の耐性（下記） | 確定 |
| `magicRates` | 属性魔法の有効率（下記） | 確定 |
| `chestRank` | 宝箱ランク | 確定 |
| 経験値、宝箱 | 敵のレア度や強さで決まる。敵の一覧を作るときに決める | 一覧作成時に決定 |
| 既存の項目 | `texture`、`aiType`、`speed`、`scale` など | 維持 |

### 攻撃属性

- 敵の攻撃には、属性がある: 無、炎、氷、雷、聖、闇、毒。魔法の属性（炎・氷・雷・聖・闇・毒）と同じ分類。
- 属性のある攻撃のダメージは、物理ダメージと属性ダメージに分かれる（例: 半々）。装備によって、ダメージが全く無くなってしまうことを避けるため。割合は敵ごとに決める。
- プレイヤー側の耐性は、装備に付く「防御属性」で表す。職業による耐性はない。
- 属性ダメージも、物理ダメージと同じ流れ（ダメージ表、防御の数値、レベルの加算、回避）で計算する。

```
属性ダメージ = ダメージ表[敵の攻撃の重さ][攻撃値] × 属性分の割合
防御         = 防具の合算（物理と同じ） ＋ 装備の防御属性の値（その属性のとき）
被ダメージ   = max(1, 属性ダメージ − 防御 − 回避)
```

- 防御属性は、強くしすぎて、ダメージが全く通らなくなることがないように、暫定の控えめな値にする（防御属性付き装備の一覧を決めるときに定める）。

## 3. 武器の耐性【確定】

敵ごとに `weaponImmunity` を1つ持つ。

| 値 | 通常の武器 | 魔法武器（+1以上） |
|---|---|---|
| `none`（既定） | 効く | 効く |
| `normal`（通常武器無効） | 効かない | 効く |
| `all`（武器全般無効） | 効かない | 効かない |

- 武器の+値は、魔法武器になることと、クリティカル率の上昇（+1ごとに+5%）だけ。+1と+2は、魔法武器としては同じ。
- 炎の剣のような武器も、属性の効果はなく、普通の+N武器（魔法武器）と同じ扱い。
- 無属性魔法は、普通の武器の攻撃と同じ扱い（`normal`、`all` の敵には効かない）。

## 4. 魔法の耐性【確定】

- 属性は、炎、氷、雷、聖、闇、毒の6種。
- 敵ごとに、属性ごとの有効率（%）を `magicRates` で持つ。未指定の属性は100%。
- 属性限定の敵は、「炎100%、他は0%」のように表す。
- 属性魔法は、敵の `weaponImmunity` に関係なく、属性ごとの有効率で決まる。

```json
"ghost":  { "weaponImmunity": "normal", "magicRates": { "fire": 150, "holy": 200, "dark": 0 } },
"wraith": { "weaponImmunity": "all",    "magicRates": { "holy": 200 } }
```

- 既存の魔法（ファイア、爆発、拡散、マジックボルトなど）への属性の割り当ては、魔法の仕様を決めるときに行う。

## 5. 宝箱ランク【確定】

- 全ての敵に、宝箱ランクを個別に、固定で決める。ランクは、木、銅、鉄、銀、金、漆黒の6段階（漆黒は、将来のレア敵・ボス用）。
- 強さに比例させない。雑魚でも、レアな敵なら、高いランクにする（はぐれメタル的な効果）。
- 現在の11種への割り当ては、`public/data/enemies.json` の `chestRank`。

| ランク | 敵 |
|---|---|
| 木 | スライム、ゴブリンアーチャー、マリア・モスキート |
| 銅 | ゴブリンシャーマン、パラサイト・ワスプ、巨大毒蛾、ポイズントード |
| 鉄 | スケルトン剣士、アシッド・ワーム |
| 銀 | タランチュラ・スワンプ |
| 金 | 人喰い箱ミミック |

## 6. 敵の数値の決め方【草案】

敵ごとに数値を決めるのではなく、強さの段階（ランク R1〜R10）に、系統の補正と特殊能力を足す。基準は、人間・平均のファイター（`scripts/stat_report.js`）。目標は、プレイヤーが5回ほど攻撃して倒せるHPと、敵の1発がプレイヤーの最大HPの約12%（防御・生命力の軽減・回避を引いたあと）。

| ランク | 想定Lv | 敵のレベル | 敵のHP | 攻撃（ダメージ表の出力、防御前） | 経験値（1体） |
|---|---|---|---|---|---|
| R1 | 1 | 1 | 38 | 13.5 | 2 |
| R2 | 5 | 5 | 38 | 14 | 22 |
| R3 | 10 | 10 | 43 | 15 | 63 |
| R4 | 20 | 20 | 52 | 17 | 179 |
| R5 | 30 | 30 | 57 | 18.5 | 329 |
| R6 | 40 | 40 | 66 | 20 | 506 |
| R7 | 50 | 50 | 72 | 22 | 707 |
| R8 | 60 | 60 | 81 | 24 | 930 |
| R9 | 80 | 80 | 97 | 27 | 1,431 |
| R10 | 99 | 99 | 112 | 30 | 1,970 |

- 経験値は、「そのレベルの次のレベルに必要な経験値 ÷ 10体」（ファイターの `expBase`）。
- 攻撃の重さ・ダイスは、ランクごとに、目標の出力になるようにスクリプトで求める。

系統の補正（HP / 攻撃）: スライム ×1.2 / ×0.8、昆虫 ×0.7 / ×1.0、爬虫類 ×1.1 / ×1.0、獣 ×1.0 / ×1.0、亜人 ×1.0 / ×1.0、人間 ×1.0 / ×1.0、アンデッド ×1.2 / ×1.0、ゴーレム ×1.5 / ×1.1、妖精 ×0.7 / ×1.1、竜 ×1.6 / ×1.3、悪魔 ×1.4 / ×1.3。

### 特殊能力（`abilities`）【草案】

敵ごとに、能力名と数値の組を持つ。通常の敵は最大2つ、ボスは最大4つ。既存の項目（`canShoot`、`stealth`、`aiType` など）は、そのまま残す。数値は、採用した能力ごとに、あとで決める。

- スタミナへの攻撃: `fatigue`（疲労: 攻撃にスタミナを削る効果を付ける）、`exhaust`（消耗: 攻撃にスタミナの消費増加や回復の遅延・停止を付ける。種類は下の表）。
- 回復・耐久: `regen`（自動回復）、`drain`（吸収）、`lastStand`（踏ん張り）、`revive`（復活）、`armorBreak`（硬質: 一定以下のダメージを通さない）、`enrage`（怒り）。
- 状態異常の攻撃: `poison`（毒）、`venom`（猛毒）、`paralysis`（麻痺）、`slow`（鈍足）、`burn`（燃焼）、`curse`（呪い）、`silence`（沈黙）、`blind`（暗闇）。
- 行動・移動: `fly`（飛行）、`burrow`（潜行）、`teleport`（瞬間移動）、`charge`（突進）、`summon`（召喚）、`split`（分裂）、`flee`（逃走）、`ambush`（待ち伏せ）。
- 遠距離・範囲: `ranged`（射撃）、`breath`（ブレス）、`aoe`（範囲魔法）、`knockback`（ノックバック）、`pull`（引き寄せ）。
- 防御・耐性: `reflect`（反射）、`barrier`（結界）、`evasion`（高回避）。武器耐性・魔法の有効率・攻撃属性は、2〜4章のとおり。
- その他: `pack`（群れ）、`rare`（レア）、`sticky`（取りつき）、`stealItem`（盗み）。

- 敵は、MPもスタミナも持たない（魔法・ブレスなどは、MPを消費せず、間隔と条件で制御する。スタミナ切れもない）。

### ボス（★）【暫定】

あとで調整する前提で、暫定値を置く。ボスは、能力値（攻撃の重さ・ダイス）をランクのまま変えず、体の大きさ・HP・攻撃パターン・自動回復・状態異常で、倒しにくくする。

- **体**: `scale` は、同ランクの通常の敵の約3倍。
- **HP**: ランクの値（系統補正後）の5倍。竜・エンペラー級は8倍、中ボス（R5以下）は3倍。
- **自動回復**: 毎秒、最大HPの0.5%（`regen` を持つボスは1%）。ダメージを受けて3秒間は止まる。
- **状態異常耐性**: 通常の敵より高い（数値は状態異常の実装時に決める）。
- **攻撃パターン（`attacks`）**: 1体に2〜4種。各攻撃が、重さ・ダイス・間隔・射程・予備動作・属性・状態異常を個別に持つ。切り替えは「距離」「HPの残り（50%以下で追加・激化）」「一定時間ごと」。
  - 体当たり（近距離・単体）、高速体当たり（予備動作が短い）、尻尾・射撃（弓矢のように速い・遠距離）、ブレス（広範囲）。
- `abilities` は常時型（`regen`・`barrier`・`summon`・`revive`・`reflect` など）を残し、`charge`・`breath`・`ranged`・`knockback` などの攻撃型は `attacks` で表す。

### スタミナへの攻撃【暫定】

敵は、MPもスタミナも持たないが、プレイヤーのスタミナを狙う攻撃・魔法の効果（`ailment`）を持てる。通常の敵は弱い効果、ボスは強い効果。攻撃魔法（範囲魔法など）にも付けられる。

| 効果 | 内容 | 目安 |
|---|---|---|
| `fatigue`（疲労） | スタミナを削る | 最大値の10〜30% |
| `regenDelay`（回復遅延） | 攻撃のあと、自然回復が止まる | 3〜8秒 |
| `regenStop`（回復停止） | 効果の間、自然回復しない | 10〜20秒（ボスの特殊攻撃、呪いなど） |
| `drain`（消耗の増加） | 効果の間、スタミナの消費が増える | 1.5〜2倍、10〜20秒（吸収系の敵、悪魔など） |

- 持久力が高いほど、効果時間は短くなる（目安: 時間 ÷ （1 ＋ 持久力 × 0.02））。耐性装備でも軽減できる（未決）。
- 治療: スタミナの薬は回復停止を打ち消す。疲労回復の香は回復遅延を無効にする。
- 「疲労の領域」（範囲内でスタミナが毎秒減る）は、実装が重いので見送り。
- どの敵・ボス・攻撃魔法にどの効果を付けるかは、ボスの `attacks` の割り当てと合わせて決める。

### 攻撃ごとの軽減【暫定】

攻撃に `area`（範囲）・`avoidable`（回避可否）・`element`（属性）・`ailment`（状態異常）を持たせ、何で軽減できるかを変える。

| 攻撃 | 当たり方 | 軽減に効くもの |
|---|---|---|
| 体当たり | 単体・回避できる | 鎧・兜の防御、回避、生命力 |
| 高速体当たり | 単体・回避しにくい（回避判定の値を半分） | 鎧・兜の防御、生命力 |
| 尻尾・射撃 | 単体・速い | 回避、盾 |
| ブレス | 広範囲・回避できない | 盾の防御、盾の属性耐性 |
| 状態異常 | 攻撃に付く | 耐性装備、治療道具 |

- ブレスは、盾なしだと鎧・兜の防御が半分だけ効く。盾ありは、盾の防御が全額効く。
- 盾に `resist`（属性ごとの軽減率。暫定は最大30%）を持たせる。防具には、状態異常の耐性を足す。
- 両手武器は盾を持てない形なら、ボス戦で武器か盾かを選ぶことになる（武器・防具側の仕様で確認する）。
- 装備が足りなくても、レベル・回復道具・耐性薬で押し切れるようにする。目安は、必須装備なしで被ダメージが約2倍。ボスの手前の店に、そのボス向けの盾・耐性装備を置く。
- 属性ごとの盾: 炎（レッド）、氷（ホワイト）、毒（グリーン）、土（アース）、闇（ダーク）、光（ゴールデン）。

## 7. 未決事項

- 敵の能力値の決め方（あとで決める）。
- 物理ダメージと属性ダメージの割合の表し方、防御属性付きの装備の一覧と暫定の値。
- 既存の `maxHp`、`attackPower` の置き換え方と、既存11種の数値の再設計（敵キャラ一覧の作成時に行う）。
- 敵ごとの経験値、宝箱を落とす確率、箱の中身（敵キャラ一覧の作成時に行う）。
- 罠と鍵の難度。
- ボスの暫定値（HP倍率・自動回復・盾の軽減率・ブレスの防御半減・回避しにくさ）の調整。ボスごとの `attacks` の割り当て。
