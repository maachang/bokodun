# アイテム仕様書

アイテム（消耗品、鍵、素材、アクセサリなど）と所持品の仕様。武器・防具の個別定義は `docs/character-spec.md` の範囲と、別途の定義に従う。宝箱は `docs/chest-spec.md`。

この文書は仕様であり、実装の根拠として扱う。変更する場合は必ずユーザーの承認を得ること。

- **確定**: ユーザーが承認した仕様。
- **草案**: 名前や数値の仮案。実際に動かして調整する前提。
- **未決**: これから決める内容。

## 1. 所持品【確定】

- FF風の個数持ち。
- 持てるアイテムの種類（ユニーク名）は、99まで。
- 1つのアイテム名ごとの個数も、99まで。

- **ゲームの実装状況（2026-11-18）**: 武器・防具の購入と所持（武器屋で、重さを選んで買う。価格は重さで決まる。持っているものだけ、ストックに入れる・着ける。`player.owned`: ID → 重さ。店は重さの制限なく売るが、筋力で持てない重さは装備できない）、所持品（`player.inventory`。種類 99・各 99 個）、道具屋・神殿での購入（`shops.json` の `itemId` のある品）、「道具」ダイアログでの使用（回復・MP・スタミナ・疲労回復の香・毒消し・麻痺治し。使うと必ず効くが、効果のないとき＝満タン・状態異常なし、は使わずに断る）、薬師・医術師の回復量の倍率、セーブ・ロードまで。**まだない**: 自動使用（4 章）、預かり（1-1）、売却、蘇生の薬・帰還の石・鍵の使用、猛毒の状態、初期の所持品・所持金（いまは空・0G）。売却は、仕様が素材（6 章）だけで、武器・防具・道具の売値は未決。

### 1-1. 預かり（冒険者ギルド）【確定】

- アイテムは、冒険者ギルドで、手数料を払って預かってもらえる（持ち歩く所持品の上限を超える分は、ここに置く）。
- 手数料の額と払い方（預けるとき、預けている間、取り出すときなど）、預かりの上限（種類・個数）、預けられる対象（装備、素材、消耗品など全部か）は、未決。
- 冒険者ギルドの建物・店主は、まだマップに無い（街の店と同様、定義が必要）。

## 2. 装備スロット【確定】

- 武器、鎧、兜、盾の4つに、アクセサリを1枠追加する（計5枠）。
- アクセサリの付与効果とランクは、「9. アクセサリ」。

## 3. 状態異常と蘇生【確定】

- 状態異常は、毒と麻痺の2つ。睡眠は作らない。
- 麻痺は、戦闘不能（死）と同じ扱い（動けない）。
- 蘇生と麻痺の回復は、別のアイテム（値段と入手条件が違うため）。蘇生の薬は麻痺に効かず、麻痺は麻痺治しだけで治る。

## 4. 自動使用【確定】

- 回復・蘇生・状態異常のアイテムは、持っていて必要になったときに、自動で使う設定ができる。
- 自動使用のON/OFFは、アイテムごとに個別に設定する。
- 発動条件の具体値（HPが何%以下など）と、複数持っているときの優先順位は、未決。

## 6. 素材【確定】（名前の割り当ては草案）

- 素材は、**宝箱の中身として出る**（敵が直接落とすのではない）。
- 素材は、敵1体（1種類）につき、1種類。複数の敵で共通にする素材もある（所持品の種類の上限 99 に当たりにくくするため）。
- 素材は売却できる。売値は、素材の種類と、「+」の数字で決まる（「+」の数字が上がるほど、高い）。
- 素材の**加工**は、とりあえず、鍛冶師（非戦闘職の「鍛冶」）だけができる。
- 素材の**合成**は、錬金術師（非戦闘職の上位職。セージ20＋鍛冶20。`docs/character-spec.md`）ができる（6-2-1、6-3）。
- 素材には**品質**がある。品質が良いものには、「+1」から「+5」（最大）の数字が付く。品質は、宝箱ランクに依存する（ランクが高いほど、良い品質が出る）。
- 「+」が付いた素材は、付かない素材とは**別の扱い**（別の種類）にする。所持品の種類の上限（99）でも、別の種類として数える。

### 6-2. 鍛冶師の加工【確定】（中身の数値は未決）

鍛冶師の加工は、2種類。

- **作成**: 素材で、新しい武器・防具を作る。
- **強化**: 既存の武器・防具を、強化する。能力が**微増**する。
- **失敗**: 強化に失敗したら、その武器・防具と、使った素材は、**ロスト**（なくなる）する。
- **素材に埋め込む情報**: 素材の属性と、強化の条件は、素材のデータに埋め込む。「+1」から「+5」の品質ごとの条件を踏まえて、強化ができる。
- **強化回数**: 1つの武器・防具に、強化できる回数の上限を設ける。強化の回数が増えるほど、リスク（失敗しやすさ）が増える。

### 6-2-1. 錬金術師の合成【確定】（中身の数値は未決）

- 錬金術師は、素材を**合成**して、新しい性能の素材を再構築できる。
- 合成に失敗すると、素材は**ロスト**する。
- 合成で、全く新しい属性ができるのではなく、素材の「+」が増える（品質が上がる）のが基本。
- 「+」が増えるほど、合成のリスクは高くなる。リスクは、錬金術師のレベルや能力でカバーできる。

### 6-3. 未決

- 素材に埋め込む情報の項目（属性、強化の条件）と、「+1〜+5」ごとの条件の中身。
- 作成のレシピ（どの素材で、どの武器・防具が作れるか。必要な素材の数と品質）と、必要な鍛冶のレベル。
- 強化の細部: 微増の量（能力のどの値が、どれだけ上がるか）、強化できる回数の上限と、回数ごとのリスクの上がり方、成功率（鍛冶のレベル、器用度、素材の品質との関係）、失敗の判定（宝箱の解除と同じ 3d6 と、奇跡・不幸を使うか）。
- 強化と、武器・防具の「+1」「+2」（魔法武器、S級・SS級）との関係（強化で「+」が付くのか、別の仕組みか）。
- 作成で失敗することがあるか（失敗すると、素材だけがロストするのか）。
- 合成の細部: 何を何個合成するか（同種の素材のみか、別の素材も混ぜるか）、「+」がいくつ増えるか、成功率とリスクの式（錬金術師のレベルや能力でのカバー）、「+5」の素材をさらに合成できるか。
- 鍛冶・錬金術師の解禁表（`public/data/jobs.json`）の草案を、レベル値つきで追加済み（鍛冶: 強化回数の上限 1/3/6、作成の素材ランク。錬金術師: 合成の「+」の上限 1/3/5、リスクの軽減）。レベルの値と、各レベルの中身は、草案で、未決。
- 宝箱ランクごとの、出る品質（+1〜+5）と確率。
- 素材の売値（基本値と、「+」の数字ごとの上がり方）。
- **所持品の種類の上限（99）の圧迫**: 素材10種に、品質 +1〜+5 を加えると、素材だけで最大 60 種類（10 × 6）になる。冒険者ギルドの預かりで逃がせるが、持ち歩く分については、素材専用の置き場（上限の外）を設けるか、上限を変えるか、品質の別扱いを素材の中にまとめるかは、未決。

## 7. 武器・防具の等級【確定】

武器・防具には、等級（レア度）がある。順番は SSS > SS > S > A（A より下の等級は未決）。

| 種類 | 等級 |
|---|---|
| +1 の武器・防具（魔法武器・魔法防具） | S級（基本） |
| +2 の武器・防具 | SS級 |
| ミスリル製品 | A級 |
| ミスリル製の +1 の武器・防具 | SS級 |
| ミスリル製の +2 の武器・防具 | SSS級 |

- **ミスリル製品の特性**:
  - 装備できる重さが、2分の1になる（同じ重さの装備を、重さの半分の扱いで装備できる。筋力の制限が緩くなる）。
  - 魔法攻撃と同様の扱いになる。
- 「魔法攻撃と同様」の細部（通常武器が効かない敵に効くか、武器全般が効かない敵にも効くか）は、未決。敵の耐性は `docs/enemy-spec.md` に従い、そこと整合させて決める。
- 「重さが2分の1」は、装備できる重さの計算（`docs/character-spec.md` の筋力と重さ）に効く。攻撃値や価格の扱いは、未決。
- **出現**: これらの武器・防具（A級以上）は、宝箱から出る。出現の条件は、宝箱ランクごとに変わる（出る最低ランクは確定。`docs/chest-spec.md` の表。確率は未決）。
- +3 以上の武器・防具の等級は、未決。
- A級より下の等級（通常の武器・防具の等級）は、未決。等級と宝箱ランクの対応（出現条件）は、`docs/chest-spec.md` に従う。

## 8. アクセサリ

付与効果ごとに、ランクが決まっている。ランクの順番は SSS > SS > S > A > B（武器・防具の等級と同じ文字。B は、アクセサリで使う。武器・防具の「A級より下」は、未決のまま）。

### 8-1. 付与効果とランク【確定】

| ランク | 付与効果 |
|---|---|
| B | 能力値が1つ上がる（+1）／毒の効果を無効にする |
| A | 複数の能力値が上がる／HP回復／歩く速度が上がる／麻痺の効果を無効にする／攻撃属性の付与（1つ）／防御属性の付与（1つ） |
| S | MPが上がる／属性を無効にする／呪文の魔力が半分になる／攻撃属性の付与（2つ）／防御属性の付与（2つ） |
| SS | HPとMPの回復／絶えず空中に浮遊する／突進攻撃が2倍の攻撃になる／攻撃属性の付与（3つ）／防御属性の付与（3つ） |
| SSS | 攻撃属性の付与（全部）／防御属性の付与（全部） |

- 防御属性の付与は、「暴挙も同様」を「防御も同様」と解釈した（確認待ち）。
