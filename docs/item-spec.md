# アイテム仕様書

アイテム（消耗品、鍵、素材、アクセサリなど）と所持品の仕様。武器・防具の個別定義は `docs/character-spec.md` の範囲と、別途の定義に従う。宝箱は `docs/chest-spec.md`。

この文書は仕様であり、実装の根拠として扱う。変更する場合は必ずユーザーの承認を得ること。

- **確定**: ユーザーが承認した仕様。
- **草案**: 名前や数値の仮案。実際に動かして調整する前提。
- **未決**: これから決める内容。

## 1. 所持品【確定】

- FF風の個数持ち。
- 持てるアイテムの種類（ユニーク名）は、99まで。
- 1つのアイテム名ごとの個数も、99まで。

## 2. 装備スロット【確定】

- 武器、鎧、兜、盾の4つに、アクセサリを1枠追加する（計5枠）。
- アクセサリの付与効果とランクは、「9. アクセサリ」。

## 3. 状態異常と蘇生【確定】

- 状態異常は、毒と麻痺の2つ。睡眠は作らない。
- 麻痺は、戦闘不能（死）と同じ扱い（動けない）。
- 蘇生と麻痺の回復は、別のアイテム（値段と入手条件が違うため）。蘇生の薬は麻痺に効かず、麻痺は麻痺治しだけで治る。

## 4. 自動使用【確定】

- 回復・蘇生・状態異常のアイテムは、持っていて必要になったときに、自動で使う設定ができる。
- 自動使用のON/OFFは、アイテムごとに個別に設定する。
- 発動条件の具体値（HPが何%以下など）と、複数持っているときの優先順位は、未決。

## 5. 最小セット【確定】（名前と価格は草案）

回復、状態異常、蘇生、帰還の石、鍵の11種に、MP回復の3種を加えた構成。

| 区分 | 名前 | 効果 | 価格（草案） | 入手（草案） |
|---|---|---|---|---|
| HP回復 | 薬草 | HPを少し回復 | 20 | 道具屋 |
| HP回復 | ポーション | HPを中程度回復 | 60 | 道具屋 |
| HP回復 | ハイポーション | HPを大きく回復 | 200 | 道具屋（街）、宝箱 |
| MP回復 | 魔力の雫 | MPを少し回復 | 25 | 道具屋 |
| MP回復 | 魔力の水 | MPを中程度回復 | 75 | 道具屋 |
| MP回復 | 魔力の霊水 | MPを大きく回復 | 250 | 道具屋（街）、宝箱 |
| 状態異常 | 毒消し | 毒を治す | 30 | 道具屋 |
| 状態異常 | 麻痺治し | 麻痺を治す | 100 | 道具屋（街） |
| 蘇生 | 蘇生の薬 | 戦闘不能から復帰（HPを少し） | 500 | 街の店、宝箱 |
| 探索 | 帰還の石 | 街へ戻る | 150 | 道具屋 |
| 鍵 | 鍵 | 宝箱の鍵を開ける（1種類のみ、ランク別にしない） | 売らない | ドロップ、イベント |

- 回復量の具体値は、能力値と職業の設計が固まってから決める（未決）。
- MP回復は、HP回復と同じ3段階。

## 6. 敵のドロップ素材【確定】

- 敵のドロップ素材と、その売却を入れる（売却用の素材）。
- 素材の一覧（敵ごと）と、売値は、未決。
- 素材が増えると、所持品の種類の上限（99）に当たりやすくなる。素材の種類数は、そのことを考えて決める。

## 7. 武器・防具の等級【確定】

武器・防具には、等級（レア度）がある。順番は SSS > SS > S > A（A より下の等級は未決）。

| 種類 | 等級 |
|---|---|
| +1 の武器・防具（魔法武器・魔法防具） | S級（基本） |
| +2 の武器・防具 | SS級 |
| ミスリル製品 | A級 |
| ミスリル製の +1 の武器・防具 | SS級 |
| ミスリル製の +2 の武器・防具 | SSS級 |

- **ミスリル製品の特性**:
  - 装備できる重さが、2分の1になる（同じ重さの装備を、重さの半分の扱いで装備できる。筋力の制限が緩くなる）。
  - 魔法攻撃と同様の扱いになる。
- 「魔法攻撃と同様」の細部（通常武器が効かない敵に効くか、武器全般が効かない敵にも効くか）は、未決。敵の耐性は `docs/enemy-spec.md` に従い、そこと整合させて決める。
- 「重さが2分の1」は、装備できる重さの計算（`docs/character-spec.md` の筋力と重さ）に効く。攻撃値や価格の扱いは、未決。
- **出現**: これらの武器・防具（A級以上）は、宝箱から出る。出現の条件は、宝箱ランクごとに変わる（出る最低ランクは確定。`docs/chest-spec.md` の表。確率は未決）。
- +3 以上の武器・防具の等級は、未決。
- A級より下の等級（通常の武器・防具の等級）は、未決。等級と宝箱ランクの対応（出現条件）は、`docs/chest-spec.md` に従う。

## 8. アクセサリ

付与効果ごとに、ランクが決まっている。ランクの順番は SSS > SS > S > A > B（武器・防具の等級と同じ文字。B は、アクセサリで使う。武器・防具の「A級より下」は、未決のまま）。

### 8-1. 付与効果とランク【確定】

| ランク | 付与効果 |
|---|---|
| B | 能力値が1つ上がる（+1）／毒の効果を無効にする |
| A | 複数の能力値が上がる／HP回復／歩く速度が上がる／麻痺の効果を無効にする／攻撃属性の付与（1つ）／防御属性の付与（1つ） |
| S | MPが上がる／属性を無効にする／呪文の魔力が半分になる／攻撃属性の付与（2つ）／防御属性の付与（2つ） |
| SS | HPとMPの回復／絶えず空中に浮遊する／突進攻撃が2倍の攻撃になる／攻撃属性の付与（3つ）／防御属性の付与（3つ） |
| SSS | 攻撃属性の付与（全部）／防御属性の付与（全部） |

- 防御属性の付与は、「暴挙も同様」を「防御も同様」と解釈した（確認待ち）。

### 8-2. 一覧【草案】（名前は仮。効果の値は、未決の箇所を「値は未決」と書いた。末尾の属性の付与は、ランクごとに行が分かれている）

| ランク | 名前（仮） | 付与効果 |
|---|---|---|
| B | 器用の指輪 | 器用度 +1 |
| B | 俊敏の指輪 | 敏捷度 +1 |
| B | 剛力の指輪 | 筋力 +1 |
| B | 生命の指輪 | 生命力 +1 |

| B | 解毒の指輪 | 毒の効果を無効にする |
| A | 戦士の腕輪 | 筋力 +1、生命力 +1 |
| A | 盗賊の腕輪 | 器用度 +1、敏捷度 +1 |
| A | 賢者の腕輪 | 知力 +1、精神力 +1 |
| A | 再生の指輪 | HPが徐々に回復する（値は未決） |
| A | 疾風の首飾り | 歩く速度が上がる（値は未決） |
| A | 麻痺除けの護符 | 麻痺の効果を無効にする |
| S | 魔力の首飾り | 最大MPが上がる（値は未決） |
| S | 炎除けの護符 | 炎の属性を無効にする |
| S | 氷除けの護符 | 氷の属性を無効にする |
| S | 雷除けの護符 | 雷の属性を無効にする |
| S | 聖除けの護符 | 聖の属性を無効にする |
| S | 闇除けの護符 | 闇の属性を無効にする |
| S | 毒除けの護符 | 毒の属性を無効にする |
| S | 節約の指輪 | 呪文の魔力が半分になる（解釈は未決） |
| SS | 回生の首飾り | HPとMPが徐々に回復する（値は未決） |
| SS | 浮遊の指輪 | 絶えず空中に浮遊する（効果の中身は未決） |
| SS | 猛進の腕輪 | 突進攻撃が2倍の攻撃になる |
| A | 炎の刻印、氷の刻印、雷の刻印、聖の刻印、闇の刻印、毒の刻印（6種） | 攻撃に、その属性が付く |
| S | 炎氷の刻印、雷聖の刻印、闇毒の刻印など（組み合わせは未決。例） | 攻撃に、その2つの属性が付く |

### 8-3. 未決

- 属性は、炎・氷・雷・聖・闇・毒の6つ（`docs/enemy-spec.md`）。「全部」は、この6つ。
- 攻撃属性の付与は、`docs/enemy-spec.md` の「武器の属性はない」との関係を決める（アクセサリで付く属性は、武器の属性ではなく、プレイヤーの攻撃の属性とする、など）。
- 防御属性の付与（軽減）と、S級の「属性を無効にする」（ダメージを受けない）の関係。

- 「MPが上がる」は、最大MPの上昇か、MP回復か。
- 「呪文の魔力が半分」は、消費MPが半分か、威力が半分か（威力が半分なら、呪い寄りの効果）。
- 毒の「効果の無効」（状態異常）と「属性の無効」（毒属性のダメージ）の関係。
- 空中浮遊で、何が変わるか（水・溶岩・罠・床の仕掛けなど）。
- HP回復・MP回復の量と間隔、最大MPの上昇量、歩く速度の上昇量。
- 複数の能力値が上がるもの（A）の組み合わせと、上がる量（+1 のまま、または +2）。
- 入手（宝箱ランクとの対応、店で売るか）と、価格。
- 呪いのアクセサリを入れるか（外せない、デメリット）。

## 9. 保留・未決

- 暗闇、松明、視界のシステムは、保留（松明とランタンも保留）。
- 宝探し系（未鑑定品、鑑定の巻物、魔法の指輪、呪いのアイテム、解呪、巻物、強化素材、伝説級武器）は、候補の段階。決まったものは、このファイルに追加する。
- 投擲物（ナイフ、爆弾、油壺など）、地図、通行証、クエスト品、宝石、食料は、候補の段階。
- 道具屋のダミー（`public/data/shops.json` の goods）は、この仕様の最小セットに合わせて、後で差し替える。
