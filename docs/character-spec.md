# キャラクター仕様書

主人公キャラクターの能力値・種族・職業・成長・戦闘計算の仕様。ソード・ワールドRPG（2.x系）を参考にした、アクション戦闘・主人公1人の設計。

この文書は仕様であり、実装の根拠として扱う。変更する場合は必ずユーザーの承認を得ること。

- **確定**: ユーザーが承認した仕様。
- **草案**: 数値や表の仮案。実際に動かして調整する前提で、データファイルに置いてある。
- 武器・防具の個別定義（種類、重さの範囲、ダイス、価格）は、この仕様の範囲外で、別途定める。

## 1. 構成と用語

| 項目 | 内容 |
|---|---|
| 能力値 | 器用度 / 敏捷度 / 筋力 / 生命力 / 知力 / 精神力 の6種（範囲 1〜50） |
| 種族 | 人間 / エルフ / ドワーフ / 魔族 / 妖精 / 獣人 / 竜人 / 小人 の8種 |
| 職業 | 戦闘職・非戦闘職、それぞれ基本職と上位職の2階層（レベル 1〜99） |
| 第一職業 | 戦闘職のうち、戦闘能力に効く1つ |
| 計測値 | キャラクター作成時にプレイヤーが止める4つの乱数（A〜D） |

## 2. 能力値

| 能力値 | DB列 | 効き方 |
|---|---|---|
| 器用度 | `dex` | 攻撃のミス率の補正（職業レベルでも補正が加わる） |
| 敏捷度 | `agi` | 移動速度 |
| 筋力 | `str` | 装備できる武器・防具の重さの上限、最大HP |
| 生命力 | `vit` | 5で割った値がダメージ軽減値、最大HP |
| 知力 | `intel` | 魔法の威力、最大MP |
| 精神力 | `mnd` | 回復魔法の効き方、最大MP |

- 範囲は 1〜50。人間の最大は 25。
- キャラクター作成時に決まり、基礎値はレベルアップで上がらない。
- 例外は、アイテム・マジックアイテム装備による補正のみ（「基礎値＋装備補正」で都度計算する）。

## 3. 種族

- 種族の効果は、能力値の上限（係数）と、最大HP・最大MPの倍率。
- 種族はキャラクター作成時に選び、変更できない。

## 4. キャラクター作成（能力値の生成）【確定】

1. 種族を選ぶ。
2. 計測値A〜Dを、ボタンで止めて決める（各 1〜12.5。信長の野望式に、数値がチラチラ変わるのをプレイヤーが止める）。
3. 能力値を、2つの計測値の合計 × 種族係数で求める。小数点以下は切り捨て、最小1。

| 能力値 | 計測値 |
|---|---|
| 器用度 | A + B |
| 敏捷度 | A + C |
| 筋力 | B + D |
| 生命力 | B + C |
| 知力 | C + D |
| 精神力 | A + D |

4. ボーナス値がランダムで決まる（1〜9。プレイヤーは止められない）。
5. ボーナス値を、プレイヤーが複数の能力値に分けて割り振る（ウィザードリィ式）。各能力値は、種族の最大値（25 × 係数）を超えない。
6. 確定する。確定するまでは何度でも振り直せるが、確定後はやり直せない（二重確定の防止はサーバー側で行う）。

- 人間の最小は2、最大は25。
- 不正対策は簡易版で、計測値の止め操作は、クライアントの値を信用する。

## 5. 最大HP・最大MP【草案】

```
最大HP = round((筋力 + 生命力) × 種族hpRate) + 第一職業レベル × hpPerLevel
最大MP = round((知力 + 精神力) × 種族mpRate) + 第一職業レベル × mpPerLevel
```

レベルでの上がり方（基本職）は `public/data/combat.json`（`hpMp`: hpPerLevel=1、mpPerLevel=0.5）。上位職は、`jobs.json` の職ごとの値を使う（6章「上位職の強さ」）。

## 6. 職業

- 職業レベルは最大99。階層は基本職と上位職の2段階。
- 必要経験値は、職業ごとの係数 `expBase` を持つ式で求める（草案: Lv n → n+1 は `round(expBase × n^1.5)`）。
- 上位職は、基本職がLv20以上で取得できる。1つの職で取れるものと、複数の職の組み合わせ（複合）で取れるものがある。
- 定義データ: `public/data/jobs.json`（草案）

### 戦闘職

| 階層 | 職業 |
|---|---|
| 基本職（4） | ファイター / シーフ / ソーサラー / プリースト |
| 上位職（8） | ナイト（ファイター20）、アサシン（シーフ20）、ウィザード（ソーサラー20）、ビショップ（プリースト20）、魔法戦士（ファイター20＋ソーサラー20）、パラディン（ファイター20＋プリースト20）、ニンジャ（ファイター20＋シーフ20）、ミスティック（ソーサラー20＋プリースト20） |

- 「第一職業」を1つだけ選び、戦闘能力と冒険者レベルは、第一職業のレベルで決まる。
- 第一職業以外の戦闘職のレベルは、戦闘に効かない（上位職の取得条件の判定にだけ使う）。

### 上位職の強さ【草案。数値は仮置きで、動かして調整する】

- 第一職業を上位職にすると、レベルは **Lv1 から始まる**（基本職のレベルは残る）。取得直後は、基本職の高レベルより弱い。
- 上位職は、基本職より、次の点で強い。

| 項目 | 基本職 | 上位職 |
|---|---|---|
| 最大HPの伸び（`hpPerLevel`） | +1 / Lv | +2 / Lv |
| 最大MPの伸び（`mpPerLevel`） | +0.5 / Lv | +1 / Lv（ウィザード・ビショップ・ミスティックは +1.5、魔法戦士は +1.25） |
| 攻撃値のレベル補正の最大（`levelBonusMax`） | +15（Lv99） | +25（Lv99） |

- 職ごとの固有の特性（`jobs.json`）:
  - ナイト（`heavyDodge`）: 重装備（`heavy`）を着けても、回避が有効。
  - ニンジャ（`dodgeAgiCoef` = 0.7）: 回避値の敏捷度の係数が高い（基本は 0.5）。
  - パラディン（`defenseRate` = 1.1）: 防御が 1.1 倍。
  - アサシン・ニンジャ: リトライクリティカルは、従来どおり（2回 / 3回）。
  - ウィザード・ビショップ・ミスティック・魔法戦士の魔法の強化（威力のプラス値・消費MPの軽減）は、8.2c の表。
- 試算（人間・平均、`scripts/stat_report.js`）: 上位職は、Lv50 で HP が基本職 Lv99 と同じ、Lv60 で攻撃が基本職 Lv99 と同じになり、Lv99 では HP が約 1.8 倍（226）、期待ダメージが約 1.4 倍。

### 非戦闘職

| 階層 | 職業 |
|---|---|
| 基本職（6） | セージ / スカウト / レンジャー / 商人 / 鍛冶 / 薬師 |
| 上位職（8） | 医術師（薬師20＋セージ20）、大賢者（セージ20）、盗賊の頭領（スカウト20）、探検家（レンジャー20＋セージ20）、大商人（商人20）、名匠（鍛冶20）、錬金術師（セージ20＋鍛冶20）、ブローカー（スカウト20＋商人20） |

- 6種すべてが同時に有効（枠の制限なし）。
- 道具の使用は失敗しない（魔法には失敗率があるが、道具にはない。`docs/item-spec.md` 5章）。薬師・医術師は、道具の「効果の大きさ・使い勝手」を上げる職業で、成功率は関係しない。
- 薬師【草案】: 回復道具（HP・MPの回復）の効果が、薬師のレベルが上がるほど大きくなる。回復量の倍率 ＝ 1 ＋ 薬師Lv × 0.01（Lv99 で約2倍）。魔法のヒールは対象外。Lv10 で状態異常を治す道具を使うと、治した直後の短い間、同じ状態異常にかかりにくくなり（耐性）、Lv20 で毒消しが猛毒にも効くようになり（医術師は Lv1 から）、Lv30 で回復道具の待ち時間が短くなり、Lv50 で＋50%（解禁表は `jobs.json`）。`jobs.json` の `healItemRatePerLevel` が傾き。
- 医術師【草案】（薬師20＋セージ20、`expBase` 40）: 回復道具の効果の上乗せ（医術師Lv × 0.5%、薬師の分と足し算。薬師Lv99＋医術師Lv99で約2.5倍）。Lv1 で未鑑定の薬・毒薬の鑑定、Lv10 で敵の状態異常の効果時間が短くなる、Lv20 で回復道具の自動使用の閾値を選べる、Lv30 で状態異常をまとめて治す、Lv50 で蘇生の薬の効果が上がる、Lv70 で歩行中のHP自然回復が増える。未鑑定品・状態異常の効果時間・HPの自然回復は、ゲームにまだ無い仕組みで、入れるときに別途仕様を決める。
- 錬金術師は、既に上位職（セージ20＋鍛冶20）。薬師との関係（取得条件に薬師を加えるか）は未決。
- レベルに応じて、冒険のフォローが解禁される（例: レベルが低いと、不明アイテムの鑑定ができず、敵の名前・詳細能力が見えない）。解禁表は `jobs.json`（草案）。上位職の効果は未定。

## 7. 経験値と職業訓練所【確定】

- 経験値は、ストック式で、戦闘などで貯める。
- 街の「職業訓練所」で、貯めた経験値を、職業のレベルアップに割り振る（戦闘職・非戦闘職で共通のストック）。
- 第一職業の変更と、職業のレベルアップは、訓練所でのみ可能。フィールドでは上がらない。

## 8. 戦闘計算

### 8.1 装備できる重さ【確定】

- 武器・防具は、重さ（1〜50、筋力と同じ範囲）を持つ。
- 装備できる重さの上限は、通常の武器・防具は筋力まで、鈍器（メイス、モーニングスターなど）は筋力の1.5倍まで。足りない場合は装備できない。

### 8.2 ダメージ【確定。ダメージ表の数値は草案】

- 武器・防具は、「ダイスの数 d 面数 ＋ 固定値」を基本値に持つ。例: ロングソード `2d6+1`（2〜13）。
- 攻撃値 ＝ ダイスの結果 ＋ 固定値 ＋ 第一職業レベルの加算（Lv99で最大+15、線形）。
- ダメージ ＝ ダメージ表[武器の重さ 1〜50][攻撃値 1〜100]。重い武器ほど、大きい。
- 攻撃にはミスの可能性があり、器用度でミス率を補正する。職業レベルでも器用度の補正がプラスされる。
  - 実効器用度 ＝ 器用度 ＋ 第一職業Lv ÷ 10（切り捨て）。ミス率(%) ＝ max(1, 30 − 実効器用度)。
  - 例: 平均Lv1（器用度14）は16%、平均Lv99は7%、器用度2のLv1は28%、器用度35のLv99は1%（下限）。
  - ミスは攻撃の最初に判定する。ミスならダメージもクリティカルもない。1ゾロは従来どおり（8.5）。
- データ: `public/data/damageTable.json`（草案。生成は `scripts/genDamageTable.js`）

### 8.2b 移動速度【草案】

- 歩く速さ ＝ 7.1 ＋ 敏捷度 × 0.1。ダッシュ ＝ 歩く速さ × 1.53。平均（敏捷度14）で既存の 8.5 / 13.0。敏捷度2で7.3、35で10.6。
- 定数: `public/data/combat.json`（`miss` / `moveSpeed`）。

### 8.2c 魔法【草案】

武器・防具と同じ「重さ＋ダイス＋ダメージ表」の仕組みで、魔法のダメージ・回復量・消費MPを決める。データ: `public/data/magic.json`、定数: `combat.json` の `magic`。

- 魔法ごとに、重さ（1〜50）とダイス `nDm＋k` を持つ。
- 攻撃値 ＝ ダイスの結果 ＋ 固定値 ＋ 第一職業レベルの加算 ＝ floor(Lv × `magicBonusMax` ÷ 99)。基本職は15、魔法系の上位職は職ごとの値（下記）。
- ダメージ（回復魔法は回復量）＝ ダメージ表[魔法の重さ][攻撃値]。
- 基本消費MP ＝ round(重さ × 係数)。係数は魔法の種類ごと: 連射弾0.25、単体弾0.36、拡散0.6、範囲0.53、回復0.4。
- 魔法力 M ＝ 知力（回復魔法は精神力）＋ 第一職業Lv × `magicLevelCoef`（基本職0.3）。
- 倍率 ＝ 重さ ÷ (M × 2)。下限 `magicCostFloor`（基本職0.5）、上限3.0。消費MP ＝ max(1, round(基本消費MP × 倍率))。
- 魔法の発動にも失敗がある。失敗率(%) ＝ clamp((重さ ÷ (M × 2) − 0.5) × 40 × 職業の緩和係数、1、95)。重い魔法ほど失敗しやすく、魔法力（知力・レベル）が高いほど下がる。
  - 緩和係数（`magicFailRate`）: 基本職 1.0、魔法戦士 0.8、ウィザード・ビショップ・ミスティック 0.6。
  - 失敗しても、MPは全額消費し、連射間隔も成功時と同じ。
  - 例（人間・平均、基本職）: Lv1 のファイア19%、爆発火球28%、重さ50は50%。Lv50 でファイア1%、爆発火球3%。魔法系上位職は Lv1 のファイア11%、Lv50 で重さ50でも3%。
- 魔法は魔法ギルドで買う。職業・レベル・知力による使用制限はなく、身の丈に合わない魔法（重さに対して魔法力が低い）は、消費MPが増えて、最大MPを超えると撃てない。
- 魔法系の上位職は、威力の加算と消費MPの軽減が、レベルに応じて大きくなる:

| 職業 | `magicBonusMax` | `magicLevelCoef` | `magicCostFloor` | `magicFailRate` |
|---|---|---|---|---|
| 基本職 | 15 | 0.3 | 0.5 | 1.0 |
| ウィザード・ビショップ・ミスティック | 35 | 0.5 | 0.4 | 0.6 |
| 魔法戦士 | 25 | 0.4 | 0.45 | 0.8 |
| 他の上位職 | 15 | 0.3 | 0.5 | 1.0 |

- 例（人間・平均の期待ダメージ Lv1 / Lv50 / Lv99）: ファイア（重さ28、2d6+3）は、基本職 12.4 / 21.0 / 30.9、魔法系上位職 12.4 / 33.4 / 55.6。
- 魔法ギルドの価格・品揃え【草案】: 価格 ＝ 重さ² × 0.6 × 種類の補正（拡散1.2、範囲1.3）を10単位に丸める。魔法は買い切りで、売却はできない。
  - 初級: マジックボルト120、ヒール240、拡散弾290。中級: ファイア470。上級: 爆発火球900、ハイヒール960。重さ50の魔法は1,500。
  - 帯（初級・中級・上級）は、街の進行による解禁を想定（条件は未決）。データ: `magic.json`（price・tier）、`shops.json`（`magic_guild`、店主は `mage_clerk_man`）。
  - 身の丈の目安: 失敗率10%以下の最大の重さは、魔法力の約1.5倍（Lv1の基本職で約21、Lv50で約43）。
- 魔法の属性（無・炎・氷・聖など）は、敵の `magicRates`（`docs/enemy-spec.md` 4章）と対応させる。魔法ギルドの価格は下記。

### 8.2d 武器・防具の価格と杖【草案】

- 価格 ＝ 購入時に選んだ重さ² × 係数 × (ダイスの平均値 ÷ 7) を、10単位に丸める。係数は、武器1.2、鎧1.2、兜0.4、盾0.4（兜・盾は防御への寄与に合わせて鎧の3分の1）。定数: `combat.json` の `equipmentPrice`。
- 重さは、購入時に自分で選べる（`equipment.json` の `weight` の範囲のうち、筋力で持てる重さまで）。店は、重さの制限なく売る。重い装備ほど高い。
- 例（筋力14の人が持てる重さ）: ダガー（8）60、ショートソード（14）240、ロングソード（14）270、メイス（21）530、レザーアーマー（14）180、アイアンヘルム（14）180。
- 杖（ワンド・スタッフ）は、武器としては弱いので、装備すると、杖のダイス結果を、魔法の攻撃値にそのまま加算する（`combat.json` の `rod`）。
- 鈍器は、重さの上限が筋力の1.5倍で、期待ダメージが高い代わりに、クリティカル率が1%（仕様書のとおり）。

### 8.3 防御【確定】

- 防具（鎧・兜・盾）も、同じダメージ表を通す。被弾のたびにダイスを振り、部位ごとの値を表で引いて、係数（鎧0.6・兜0.2・盾0.2、合計1.0）で合算したものが防御。
- 被ダメージ ＝ 攻撃 − 防御 − 生命力による軽減（生命力 ÷ 5）。結果が1を下回る場合は1ダメージ。
- 防具の部位が空の場合は、その部位の寄与は0。

### 8.3b 回避【確定。係数は草案】

- 回避値 D ＝ 敏捷度 × 0.5 ＋ 第一職業レベル × 0.1。
- 被弾のたびに、0〜D の乱数を軽減量として、ダメージから引く。ただし被ダメージは最低1。
- 金属製の重装備（`equipment.json` の `heavy`。チェインメイル以降の鎧、鉄製の兜、盾）を着けていると、回避は無効。軽装のときだけ有効（職業は問わない）。
- こちらの防御で1ゾロが出たときは、回避値は0（軽減なし）。通常の敵のクリティカルは、回避の対象になる。

### 8.4 クリティカル【確定】

- 基本クリティカル率
  - 通常の武器: シーフ以外の戦闘職は一律10%、シーフ・アサシン・ニンジャ（シーフ系）は一律20%。
  - 鈍器: 全職業が一律1%。
  - シーフ系の20%は、軽い武器（重さ ≤ 筋力の半分）を持つときだけ。重い武器ではファイターの半分（5%）になる。
- シーフ系が重装備（`heavy`）を着けると、クリティカル率にペナルティ（草案: 鎧・兜・盾それぞれ−5%。下限1%）。ファイターなど他の職業には影響しない。軽い武器の条件とは、重ねて適用する。
- マジックアイテム（例: ダガー+1）は、クリティカル率が底上げされる（+1ごとに+5%）。
- クリティカル時のダメージは、ダメージ判定の1.5倍。
- **リトライクリティカル**: 最初のクリティカルが出たあとに、追加でクリティカルを抽選できる回数。

| 職業 | リトライ回数 |
|---|---|
| ファイターなど | 0回（最初のクリティカルで終わり） |
| シーフ | 1回 |
| アサシン | 2回 |
| ニンジャ | 3回 |

- 各回のダメージは、その都度ダメージ判定をして合算する。リトライでクリティカルが出たら続け、出なければ通常ダメージを加えて終了する。リトライ回数を使い切ったら終了する。
  - 例（シーフ）: クリティカル10 ＋ 通常3 ＝ 13
  - 例（アサシン）: クリティカル10 ＋ クリティカル8 ＋ 通常3 ＝ 21

### 8.5 1ゾロ（ダイスの目がすべて1）【確定】

- 攻撃で出たら、必ず最大1ダメージ。
- 防御で出たら、相手の攻撃は必ずクリティカル。相手がシーフ系なら、続けてリトライクリティカルで上乗せできる。

### 8.6 戦闘定数

クリティカル率、鈍器の倍率、防御係数、1ゾロなどの定数は `public/data/combat.json`（草案）。

## 9. 保存方式【確定】

- キャラクター情報は、SQLite3 に保存する。テーブル定義は `schema/rpg.sql`（`characters` / `character_jobs`）。
- 全テーブルに `user_id` を持ち、`$db.forUser` 経由でアクセスする。
- `user_id` は、当面、匿名セッション（`session.js`）で発行した ID とする（ログインは将来）。
- 種族・職業・戦闘定数などの静的定義は、`public/data/` の JSON で持つ。
