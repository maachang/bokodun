# 宝箱仕様書

宝箱のランク、セキュリティ装置、解除の判定の仕様。敵ごとの宝箱ランクは `docs/enemy-spec.md` の「宝箱ランク」に従う。アイテムは `docs/item-spec.md`。

この文書は仕様であり、実装の根拠として扱う。変更する場合は必ずユーザーの承認を得ること。

- **確定**: ユーザーが承認した仕様。
- **草案**: 名前や数値の仮案。実際に動かして調整する前提。
- **未決**: これから決める内容。

## 1. 宝箱ランク【確定】

- ランクは、木、銅、鉄、銀、金、漆黒の6段階（漆黒は、将来のレア敵・ボス用）。
- ランクは、敵ごとに固定で決める（`docs/enemy-spec.md` の「宝箱ランク」）。強さには比例させない。
- ランクが高いほど、レアなアイテムが出る。解除も難しくなる。

## 2. セキュリティ装置【確定】

- 宝箱は、必ず鍵がかかっているわけではない。鍵は、宝箱のセキュリティ装置の1つ。
- 装置の種類: 鍵、罠（ダメージ）、毒針（毒）、爆発（大ダメージ）、警報（周囲の敵を呼ぶ）など。
- 1つの宝箱に、装置が0〜複数つく。装置の数は、ランクが高いほど増える方向（具体値は未決）。
- 爆発などのダメージは、宝箱ランクで決める（具体値は未決）。

## 3. 解除の手段【確定】

- **鍵アイテム**: 鍵のセキュリティだけを開ける。罠などには効かない。
- **スカウト職の能力**: 装置ごとに、判定して解除する（下記）。
- **魔法**: 鍵は「アンロック」、罠の解除は「トラップ」。2つは別々の魔法で、同じ魔法属性。

## 4. 解除の判定【確定】

- スカウトの判定: 挑戦値（スカウトのレベル＋器用度）＋ 3d6 の合計が、宝箱ランクの難易度以上なら成功。
- 難易度は、宝箱ランクで決まる。ランクが高いほど難しい（値は未決）。
- 装置ごとに、別々に判定する。
- 魔法の成功率は、固定で、知力で補正する。スカウトより手軽だが、リスクを伴う。スカウトのレベルが高い場合は、スカウトのほうが確実で、逆転する。
- **奇跡**: 3つのダイスが全部6（約0.46%）なら、何があっても成功する。スカウトと魔法の両方に適用する。
- **不幸（ファンブル）**: 3つのダイスが全部1（約0.46%）なら、自動で失敗する。スカウトと魔法の両方に適用する。
- ソード・ワールドの「6ゾロ＝奇跡、1ゾロ＝不幸」を参考にしたもの。ダイスが多いほど、奇跡と不幸の割合は減る。

## 5. 失敗時の結果【確定】

- 解除に失敗した装置は、作動する。
- 中身が取れるか取れないかは、ランダム（確率は、宝箱ランクで定義）。
- 不幸（ファンブル）のときは、装置が必ず作動し、中身が取れなくなる確率を上乗せする。

## 6. 数値（難易度の草案）

3d6（幅 3〜18）と、挑戦値（最大 99＋50＝149）に合わせて、調整が必要。以下は、旧草案の値で、**そのまま使えない**。

| ランク | 難易度（旧草案） |
|---|---|
| 木 | 10 |
| 銅 | 25 |
| 鉄 | 40 |
| 銀 | 60 |
| 金 | 80 |
| 漆黒 | 100 |

## 7. 未決

- ランクごとの難易度の値（3d6 の幅と、挑戦値に合わせる）。
- 魔法の成功率の値と、3d6判定との合わせ方。
- 不幸のときの、中身が取れなくなる確率の上乗せ量。
- 装置の数（ランクごと）と、ダメージの値。
- 解除できなかった（挑戦しなかった）ときの扱い（スカウトも魔法も使えない場合に、そのまま開けられるか）。
- 宝箱を落とす確率と、箱の中身（敵の一覧の作成時に決める）。
