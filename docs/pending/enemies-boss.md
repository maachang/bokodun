# 保留・未反映: 敵・ボス・守衛・戦闘の方針
**読む条件**: 敵・ボス・守衛・戦闘・宝箱ランク・隠密・ガーゴイルの作業をするとき。

## 漏れ
- 【漏れ】ボスの割り当て（11-01 承諾）: `attacks`（攻撃パターン）が 127 体に 0 件。スタミナへの攻撃（疲労・回復遅延）の処理なし。HP 倍率（`hpMul`）は入っている。
- 【漏れ】敵の宝箱ランク: 127 体のうち 12 体だけ（10-27 の指示は「全ての敵に」）。
- 【漏れ】人間系の敵（山賊・ならず者）は、街・村の中で戦えない。戦えるのは、外・山賊に占領された街・下水道・どや街など、戦えるフィールドとして定義した所（10-28 の決定）: マップ側の定義も処理もない。
- 【漏れ】守衛（最強の非ボス・戦わない・違反行為で街に入ると追われる）: 追いかける挙動・数値・配置が未実装。
- 【漏れ】敵の隠密（索敵）の数値表: データ・コードにはあるが、仕様書に書かれていない。

## 保留
- 【保留】守衛の数値（ユーザーが保留）。敵 102 体のランク・特殊能力の割り当て・ボスの数値は、「仮でバランスを決めた。あとで直す」（11-02）。
- 【保留】時間帯による敵の種類・強さの変化（ゲームができてから）。
