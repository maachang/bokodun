# Bokodun 3D (ボコスカダンジョン 3D)

90年代レトロPC/家庭用ゲーム機（イース・ウルティマアンダーワールド・ダンジョンマスター等）のテイストをオマージュした、**ブラウザ上で動作するレトロ疑似3DアクションRPG**です。

---

## 🎮 主なゲーム特徴

### 1. 共通エンジン＆データ駆動（JSON）アーキテクチャ
- **ハードコードの完全撤廃**: マップ、地形オブジェクト、敵キャラクターのパラメータをすべて独立した JSON ファイルで管理。
- **オブジェクトカタログ方式**: 地形やギミックを `objects.json` に定義することで、草原に遺跡レンガ壁を置いたり、洞窟に地底湖やマグマを流すなど、シーンを越えたオブジェクトの共用が可能。

### 2. 4大シーン（ゾーン）
- **地下迷宮 (Dungeon)**: 閉ざされた石とレンガの迷宮。トゲ罠やバリア床、昇降式ドアが配置されたクラシックな迷宮。
- **エメラルド平原 (Grassland)**: 開けた青空と草原。自然な凹凸の樹冠（モサモサした樹林帯）で囲まれた外周、砂浜、浅瀬、木橋の架かる池が広がる。
- **岩山の頂 (Rocky Mountain)**: 険しい岩肌がそびえる山岳地帯。灼熱の溶岩溜まりや滑る氷床が存在。
- **地底洞窟 (Cavern)**: 薄暗い天然岩盤と緑の苔に覆われた鍾乳洞。天井があり、地底湖や隠し魔法陣が点在。

### 3. 多彩な地形・床ギミック
- **池・浅瀬（立体窪地）**: 基準面より低く窪んだリアルな水面構造。浅瀬は水に浸かって歩行可能（水圧で速度低下）、深い池は歩行侵入不可だが魔法弾は通過可能。
- **ドラクエ風バリア床**: 歩くごとに「ジャッ！」というファミコン特有のノイズ音と強烈な青色電撃フラッシュが発生し、ダメージを受ける。
- **溶岩 (Lava)**: 踏むと継続的な火炎ダメージと火花が発生。
- **毒沼 (Poison Swamp)**: 移動速度低下＋毒スリップダメージ。
- **氷床 (Ice)**: 摩擦が小さくツルツルと滑る。
- **敷石の小道 (Cobblestone)**: 移動速度が 25% アップ。
- **魔法陣 (Magic Circle)**: 乗っている間、MPが高速回復するオアシス。
- **トゲ罠 (Spike Trap)**: 踏むと飛び出す針で大ダメージ。
- **ダンジョンの扉 (Door)**: 壁の間に自然に収まる重厚な木鉄扉。近づくとSEとともに天井へスライド上昇して開く。

### 4. 戦闘・アクション
- **イース風「半ずらし」体当たり戦闘**: モンスターの正面を外して半分ずらしてぶつかることで、ノーダメージで大ダメージを与えるレトロアクション。
- **ファイアボール（魔法攻撃）**: MPを消費して遠距離攻撃。池の上を飛び越えて対岸の敵を射程に収めることが可能。
- **モンスターAI**: スライム（近接追尾）、ゴブリン魔導士（距離を取って暗黒魔法を連射）、スケルトン剣士（俊敏な近接攻撃）。

## 📁 ディレクトリ構成

```text
bokodun/
├── package.json               # プロジェクト定義・テストスクリプト
├── public/
│   ├── index.html             # ゲームエントリーポイント（HUD、描画キャンバス、AI工房）
│   ├── data/
│   │   ├── objects.json       # 共通オブジェクトカタログ（壁、床、ギミック定義）
│   │   ├── enemies.json       # 敵パラメータ定義（HP、攻撃力、速度、AI種別）
│   │   └── maps/              # マップ（シーン）定義JSON
│   │       ├── dungeon.json       # 地下迷宮
│   │       ├── grassland.json     # エメラルド平原
│   │       ├── rockymountain.json # 岩山の頂
│   │       └── cave.json          # 地底洞窟
│   ├── images/
│   │   ├── objects/           # 地形・背景画像（樹林帯、バリア、洞窟岩肌、木など）
│   │   └── enemies/           # 敵スプライト（スライム、ゴブリン、スケルトン）
│   └── js/
│       ├── game.js            # メインゲームエンジン（ループ、レンダリング、物理、当たり判定）
│       ├── textures.js        # プロシージャルレトロテクスチャ生成エンジン
│       ├── entities.js        # モンスターAI・射出物（ファイアボール）
│       ├── audio.js           # Web Audio API レトロサウンド・SEシンセサイザー
│       ├── particles.js       # パーティクルシステム（火花、爆発、魔法の軌跡）
│       ├── sdAssetManager.js  # AI画像生成サーバー連携マネージャー
│       └── three.module.js    # 3Dレンダリングライブラリ
└── test/
    └── game_integrity.test.mjs # 自動整合性・構文テストスイート
```

## 🕹️ 操作方法

| キー / 操作 | アクション |
| :--- | :--- |
| **W / ↑** | 前進 |
| **S / ↓** | 後退 |
| **A / D** | 左右平行移動（ストレイフ） |
| **Q / E** または **← / →** | 左右旋回（視点回転） |
| **Space** または **F** | ファイアボール（魔法弾発射） |
| **画面クリック** | マウス視点操作（ポインタロック）/ 魔法発射 |

## 🧪 テスト・品質保証

開発時のタイポ、未定義関数の呼び出し、変数のスコープ外参照、未登録のマップ記号などを未然に防ぐため、Node.js 標準テストランナーを用いたテストスイートを配備しています。

```bash
npm test
```

### 検証項目
1. **JSON Schema & Integrity**: 全マップ・オブジェクト・敵定義の構文および記号の漏れがないかを網羅検証。画像アセットの実体存在チェック。
2. **Audio Method Integrity**: 呼び出されているすべてのサウンド関数が `SoundFX` クラスに存在するかを検証（未定義エラーの防止）。
3. **Texture & Property Integrity**: オブジェクト定義とテクスチャ初期化の整合性を検証。
4. **Compiler Syntax & Scope Analysis**: 全フロントエンド JS ファイルに対して `node --check` による厳格なコンパイラ構文解析を実行。
